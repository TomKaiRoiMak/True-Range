0.9.3 beta

- Frame rate with things on the ground (the Great Depths Worm, Toadstool, Crystal Deerclops): each thing's pieces now kept together under one parent and moved as one - the game told only where the thing is, each frame; its pieces told again only when what's drawn changes (it turns, its colours change). Before, every piece was laid again every frame: thousands of calls to the game a frame - with one worm the frame rate fell from 60 to under 50 (off: 59-60 with five). Calls to the game a frame in a test fight: worm 4352 -> 187, Toadstool 774 -> 53
- Boss moves' shapes kept the same way, once they stop turning
- A shape worked out once for its size too - a pound's ring spreading could reuse a smaller one's pieces
- Round things drawn unturned (a worm segment, a mushroom bomb, a spore cloud, the Crystal Deerclops' circles - every cell of them a disc round them): turned a hair each frame as the game slides them between its ticks, each frame was a new shape laid piece by piece - the groups above never kept. Calls to the game a frame with the worm turning so: 11167 -> 204. Same strikes caught and missed in every log kept
- Less work per thing on the ground every frame (measured in the game: a worm's 81 drawn segments took 7 ms, the Crystal Deerclops' 262 spikes 8.6 ms):
  - the bosses near asked where they are once a frame, the worm's holes too - not once for every thing
  - a piece not asked whether it's still there each time it's laid (hundreds of calls to the game a frame)
  - a thing new to the screen given pieces that already lie as it wants them, if any - not laid anew
  - each spike's list written over, not made anew every frame
- Round things drawn unturned only in what's drawn - where they strike is still worked out as turned (the same strikes caught and missed in every log kept)
- (testing) [tr_perf] lines now say how many things, how many drawn, the time drawing them, pieces laid, calls made, groups laid again and moved
- A thing on the ground drawn just as last frame is kept as it was - nothing about it worked out again: turned the same, where it was (or moved, the worm's segments: only moved), no part of it due to change colour yet (the next moment one does is worked out as it's drawn). A spike whose strikes are all past is passed over at once while it stands there (the Crystal Deerclops' spikes stand long after). Only whether you're in it is looked at again. The mod's own work with the worm and the deerclops' spikes: about 24000 lines of Lua a frame -> 14600 (the game's Lua, slower than the test's: the time it took in the game was mostly this)
